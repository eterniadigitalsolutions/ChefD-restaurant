# Elegencia — Independent React Recreation

A fresh React + Vite restaurant website inspired by the public Elegencia demo.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
```

## GitHub

Create a repository, then:

```bash
git init
git add .
git commit -m "Initial React restaurant website"
git branch -M main
git remote add origin YOUR_GITHUB_REPOSITORY_URL
git push -u origin main
```

## Notes

This is an independent recreation and does not contain the original ThemeMarch source code.
Replace the demo image URLs with your own licensed images before production use.
